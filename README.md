# SmugMug WordPress Importer

A custom WordPress plugin that imports an entire SmugMug gallery into a WordPress post as individual image blocks.

## Goal

Instead of manually copying 20–30 image URLs into a blog post, the plugin will:

1. Connect to SmugMug
2. Let me choose a gallery
3. Import every image into WordPress in gallery order
4. Insert a blank paragraph after each image so I can write my story

Images remain hosted on SmugMug.

This project is for personal use.
